# Experiments

One row per attempt, including the ones that got worse. State the validation scheme: a score without
it cannot be compared.

**How we got here.** Each idea is scored offline first (rows 3–16, IPS on the old carousel log), and only
an offline winner goes live. Live, the serving loop splits requests between versions by a hash of
`request_id` (`--versions`), and the leaderboard API (`/api/state?by=model&from=&to=`) gives each
version's expected conversion in the same minutes. Expected conversion does not depend on luck, so it
separates versions within an hour; purchases we count ourselves need many hours. Conversion moves with the
time of day (the baseline goes from 0.69 to 0.79 % in one afternoon), so we compare versions in the same
window, or each one as a ratio to the baseline. Path so far: baseline (1–2) → Destroyer wins offline (5)
and live (17) → Terminator wins offline (14) and live (19–20) → Terminator serves alone.
